# C# Beginner Projects

## Welcome!

This folder contains simple and practical C# projects designed for beginners.

## What’s Included

The projects in this folder cover a variety of fundamental C# topics, including:

- **Arrays**  
- **Lists**  
- **if statements**  
- **while loops**  
- **for loops**  
- **foreach loops**  
- **string manipulation**  
- **StringBuilder usage**  
- **FileInfo class for file operations**

These examples are ideal for building a solid foundation in C# programming by learning how to control program flow, manage collections, work with text, and handle files.

## Development Environment

All projects were created and tested using **Microsoft Visual Studio**.

## Feel free to explore

Feel free to explore, run the code, and see how each concept works in practice.  
Happy coding!
