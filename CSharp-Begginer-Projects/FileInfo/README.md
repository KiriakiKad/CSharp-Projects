# C# Beginner Projects

## Welcome!

This folder contains simple C# projects perfect for beginners.  
You will find examples using the **FileInfo** class — a useful way to access information about files and perform basic file operations in C#.

## Development Environment

All projects were created and tested using **Microsoft Visual Studio**.

## Feel free to explore

Feel free to explore, run the code, and see how everything works in action.  
Happy coding!
