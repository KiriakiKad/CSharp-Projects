# C# Advanced Projects

## Welcome!

This folder contains advanced C# projects designed to strengthen understanding of **object-oriented programming**, **generics**, **delegates**, **events**, **LINQ**, **async/await**, and other intermediate-to-advanced C# concepts.

## What’s Included

The projects in this folder cover a variety of important C# topics, including:

- **Generics Exercise**  
  - Implementing a generic list class (`GenericList<T>`).  
  - Storing items of any type while ensuring **type safety**.  
  - Methods include `Add` and `Get` with proper validation.

- **Delegates Calculator**  
  - Using **delegates** to represent multiple operations (`Add`, `Subtract`, `Multiply`, `Divide`).  
  - Demonstrates **multicast delegates** by combining multiple operations into a single delegate.

- **Lambda Filtering**  
  - Using **lambda expressions** (`Action<int>`) to filter and process collections.  
  - Example: determining even/odd numbers and numbers greater than 5.

- **Product Events**  
  - Modeling a `Product` with a **StockDepleted event**.  
  - Demonstrates **event subscription** with multiple services (`EmailNotificationService`, `SmsNotificationService`).  
  - Shows how **events** can notify multiple services about changes in state.

- **Students Degree LINQ**  
  - Using **LINQ** to query a collection of `Student` objects.  
  - Filtering, ordering, and projecting data in a concise and readable way.

- **Async Data Processing**  
  - Demonstrates **asynchronous programming** with `async/await`.  
  - Fetching data asynchronously (`FetchDataAsync`) and processing it without blocking the main thread.

## Key Concepts Practiced

- **Generics** for type-safe reusable classes.  
- **Delegates & Multicast Delegates** for flexible method invocation.  
- **Events** for decoupled notifications and service integration.  
- **Lambda Expressions** for concise data operations.  
- **LINQ Queries** for filtering, ordering, and projecting collections.  
- **Async/Await** for non-blocking asynchronous programming.  
- **Object-Oriented Principles**: Abstraction, Inheritance, Polymorphism, Interfaces, Encapsulation.  
- **Defensive Programming** and proper validation.

## Development Environment

All projects were created and tested using **Microsoft Visual Studio**.
