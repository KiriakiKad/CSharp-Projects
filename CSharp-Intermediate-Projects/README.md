# C# Intermediate Projects

## Welcome!

This folder contains intermediate-level C# projects designed to deepen understanding of object-oriented programming (OOP) concepts and best practices.

## What’s Included

The projects in this folder cover a variety of important C# topics, including:

- **Custom Stack (LIFO implementation)**  
  - Creating a stack from scratch with `Push`, `Pop`, and `Clear` methods.  
  - Handling edge cases (null objects, popping from empty stack).  

- **Stopwatch**  
  - Measuring elapsed time using `DateTime` and `TimeSpan`.  
  - Defensive programming with exceptions to prevent misuse (e.g., multiple starts or stops).  

- **Post Voting System**  
  - Modeling a `Post` with title, description, creation date, and votes.  
  - Implementing upvotes and downvotes with validation (no negative votes).  

- **Database Connection Framework**  
  - Using **abstraction** and **inheritance** to represent different database types (SQL, Oracle).  
  - `DbConnection` as an abstract base class, extended by `SqlConnection` and `OracleConnection`.  
  - `DbCommand` class to execute instructions using polymorphism.  

- **Workflow Engine**  
  - Designing extensible workflows using **interfaces** (`IActivity`).  
  - Adding activities (`UploadVideo`, `SendEmail`) and running them through a workflow engine.  
  - Demonstrates polymorphism and the power of interfaces.  

## Key Concepts Practiced

- **Abstraction**  
- **Inheritance**  
- **Polymorphism**  
- **Interfaces**  
- **Encapsulation & validation**  
- **Defensive programming with exceptions**  

## Development Environment

All projects were created and tested using **Microsoft Visual Studio**.

## Feel free to explore

Explore each project, review the code, and run the examples to see how these OOP principles are applied in practice.  
These exercises will help strengthen your ability to design clean, extensible, and robust applications in C#.

Happy coding!
