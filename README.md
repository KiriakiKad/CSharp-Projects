# C# Projects Repository

📌 **Overview**

This repository contains three folders representing different skill levels in C# projects:

- **Beginner** 🟢  
- **Intermediate** 🟡  
- **Advanced** 🔴  

Each folder includes projects appropriate for that level, helping you progress step-by-step from basic to more complex C# programming.

💻 **Development Environment**

All projects were created and tested using **Microsoft Visual Studio**.  
Make sure your installation includes the **.NET desktop development** workload.

## 🚀 How to Run the Projects

1. **Clone the repository** to your local machine:
   ```bash
   git clone https://github.com/KiriakiKad/CSharp-Projects.git

2. Open Microsoft Visual Studio
3. Navigate to the desired project folder and open the .sln file.
   Example:
    ```bash
    CSharp-Advanced-Projects\AsyncDataProcessing\AsyncDataProcessing.sln
    ```

4. Build the solution:
   - Go to Build → Build Solution
   - or press Ctrl + Shift + B
5. Run the project:
   - Press F5 → Run with debugging
   - Press Ctrl + F5 → Run without debugging

## 📂 Folder Structure

Each project folder typically contains:

- `.cs` files → C# source code
- `.csproj` → Project configuration
- `.sln` → Solution file for Visual Studio

⚠️ You do not need the `bin/`, `obj/`, or `Properties/` folders – they are generated automatically when you build the solution.

## 🛠️ Notes

- All projects are self-contained.  
- If you encounter errors, check that your Visual Studio setup includes the required .NET workload.  
- Designed for learning & practice across different difficulty levels.

## 📖 Levels

- **Beginner** → Fundamentals, syntax basics, simple applications.  
- **Intermediate** → OOP concepts, file handling, collections, LINQ.  
- **Advanced** → Asynchronous programming, complex C# features.
